Change OAuth App

One-time setup. Register a free GitHub OAuth App so this extension can ask for your permission. After this, "Connect with GitHub" is just one button click.

  1. Open github.com/settings/applications/new
  2. Fill in any Application name (e.g. LeetCode Enforcer) and any Homepage URL (e.g. http://localhost)
  3. Check Enable Device Flow
  4. Click Register application → copy the Client ID shown
  5. Paste it below, hit Save
